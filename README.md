Token launch radar that ranks pre-token protocols by implied value, built from a DefiLlama snapshot of 758 protocols. It scores every protocol on a value model derived from live-token comparables (per-category median market-cap/TVL, shrunk toward the global median where a category has few comparables, clamped, with a pre-token discount, growth/maturity/chain-breadth factors, and a quartile confidence band on every row), covers all 40 watchlist protocols, and writes a sortable/filterable dashboard plus concrete farm plans — sized down where the comparables disagree — with costs and times for the top opportunities.

## Run it

```sh
node main.ts
```
